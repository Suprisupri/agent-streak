## Awards

### Project Awards — $29,000 each (top 10 projects per award)

| Award | How it's judged | Prizes |
|---|---|---|
| **Growth Award** | On-chain metrics ranking: number of Agent ID addresses interacting, volume, transaction count | 1st $10,000 · 2nd $6,000 · 3rd $4,000 · 4th $3,000 · 5th $2,000 · 6th–10th $800 each |
| **Innovation Award** | Jury panel: Agent ID depth 30%, practicality 25%, completion 25%, innovation 20% | Same prize structure as Growth Award |

- A single project can win **only one** award.
- The top 20 winning projects also receive a spot to claim a **two-digit Agent ID**.

### Community Promotion Award (separate)

- 2,000 USDC total, split across 20 winners ($100 each).
- For original X posts about participant projects using the hashtags `#BinanceWalletHackathon` and `#AgenticWallet`.
- Post links are submitted via the Binance campaign survey.

## Requirements

- Contract deployed on **BNB Chain**.
- Source code **verified and open-source** on BscScan.
- Product must **actively use Agent ID**.
- **One project per team.**
- Innovation Award eligibility: product must be **live** and have at least **30 Agent ID addresses** interacting with the contract during the submission period.

## Red Lines (do not cross — disqualification risk)

- No QR login on the web.
- No prompts that bypass the user's transaction confirmation.
- No asset transfers without user permission.
- Contract must be open-source, with owner permissions documented.
- No "Binance" / "BNB" naming in project name, token, or domain.
- No collecting seed phrases, private keys, or API secrets.
- No promised returns.
- Trading products must show a risk warning (not applicable — Agent Streak is not a trading product).
- Agent ID must NOT be packaged as a tool to "find someone's wallet from their name".
- No volume manipulation or mass fake accounts.

## Our Project

**Agent Streak** — daily check-in dApp for Agent ID holders: on-chain streaks, soulbound milestone badges (7/14/30 days), and a public leaderboard from on-chain events. No user funds held (no deposits, no paid mints); owner permission is emergency pause only. See `SUBMISSION-DRAFT.md`, `SUBMISSION-CHECKLIST.md`, and `PROMOTION-PLAN.md` in this folder.
